Crafting Grid adds a compact icon grid to Casualties: Unknown's original crafting menu.

- Hand-picked 12-column layout, native search, filters, tooltips, and recipe details.
- Left click selects; right click crafts, including on the large native recipe icon.
- Ingredient check/X badges and a new top-right dot on recipes that use the selected output.
- Gap-free tiles, dim unavailable recipes, selected outline, and a Grid checkbox to restore the original list.
- Live recipe discovery, with unmapped and modded recipes appended at the end.

**Install:** Requires BepInEx 5 Windows x64 / Mono. Close the game and copy the ZIP's `BepInEx` folder into the folder containing `CasualtiesUnknown.exe`, merging folders. Start the game and press C. No manual loader-config edits are required.

Tested with the full game 1.0 and BepInEx 5.4.23.5. Demo and multiplayer are untested.
